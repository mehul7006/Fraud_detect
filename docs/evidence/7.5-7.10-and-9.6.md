## Bugs found and fixed
- **Repeated alerts:** SMS apps re-post earlier notifications when the thread updates; login-code and new-device
  notices alerted again each time. Now one alert per notice per 5 minutes (in-memory text hash, code never stored).
- **Android 14 full-screen alerts silently missing:** the app never checked `canUseFullScreenIntent()`. Now a card
  explains it and opens the exact Settings page; without it a high-priority notification is still shown.
- **Lock-screen privacy:** the dangerous link was readable on a locked phone. Now a public version without details.
- **An alert could be blocked forever** if reading the optional emergency contact failed / hung (found by tests);
  now a 2 s timeout and a failed read just means "no contact".
